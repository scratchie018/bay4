# Bay 4 · Hook & Ring

A first-person free-for-all in a sodium-lit warehouse bay. Karambits only, or AWPs.

**Play:** https://scratchie018.github.io/bay4/

- **Play vs bots:** 7 bots, three difficulties, first to 15 kills or most kills in 3:00.
- **Play online:** pick a room code and share it with friends. Everyone with the same code and mode plays together, first to 15. No account needed. The first player in a room hosts it; if they leave, someone else takes over.

Cheats: press ` (or Esc) in a bot match for god mode, aim assist, wallhack, moon jump and more. Online, cheats only work in cheats rooms: turn on "Cheats room" next to the room code. Cheats rooms and normal rooms never mix.

**Team modes:** free-for-all, or 1v1 up to 8v8 (Hooks vs Rings, no friendly fire). Against bots, bots fill both teams; online, players join the smaller team.

**Maps:** Bay 4, Quarry, Market, Foundry, Frost, Shipyard, Arena and Lab. They're generated by `maps/build_maps.py` in the same format as the Bay Forge map editor. Textures are from Screaming Brain Studios' Tiny Texture Pack 2 (CC0, see `maps/tex/`).

**Custom maps:** build one in Bay Forge, copy its map code, then press "Load map code" in the menu. Online, everyone who joins your room downloads the host's map automatically.

Controls: WASD move · mouse aim · left click slash / fire · right click stab / scope · Shift dash · Space jump · C crouch · 1 / 3 / Q swap weapons · R reload · F inspect · Tab scores · Esc pause.

Online play connects players directly with WebRTC ([PeerJS](https://peerjs.com/)). Some school and work networks block that.
